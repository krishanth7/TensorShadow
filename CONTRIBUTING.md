# Contributing to TensorShadow

First off, thank you for considering contributing to TensorShadow! It's people like you that make TensorShadow such a great tool.

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct. Please report unacceptable behavior to `contact@TensorShadow.ai`.

## How Can I Contribute?

### Reporting Bugs

- Before creating a bug report, please check the existing issues.
- Use a clear and descriptive title.
- Describe the exact steps which reproduce the problem in as many details as possible.

### Suggesting Enhancements

- Check if the enhancement has already been suggested.
- Explain why this enhancement would be useful to most TensorShadow users.

### Your First Code Contribution

1. Fork the repository.
2. Create a new branch (`git checkout -b feature-name`).
3. Make your changes.
4. Ensure your code follows the project's style guide.
5. Submit a pull request.

## Style Guides

### Python (TensorFlow)
- Follow [PEP 8](https://www.python.org/dev/peps/pep-0008/).
- Use type hints for all function signatures.

### Go (Golang)
- Follow [Effective Go](https://golang.org/doc/effective_go.html).
- Run `go fmt` before committing.

### R (Analytics)
- Follow the [tidyverse style guide](https://style.tidyverse.org/).

## Commit Messages

- Use the present tense ("Add feature" not "Added feature").
- Use the imperative mood ("Move cursor to..." not "Moves cursor to...").
- Limit the first line to 72 characters or less.

Thank you for your contributions!
